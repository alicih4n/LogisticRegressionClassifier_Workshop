## Project Overview

### What is This Project About?

This project covers the implementation and understanding of **Logistic Regression** as a fundamental statistical classification algorithm in machine learning. The main focus is on binary classification problems where the goal is to predict one of two possible outcomes (e.g., Pass/Fail, Yes/No).

### Key Topics Covered:

1. **Statistical Classification** - Understanding classification problems in machine learning
2. **Logistic Regression vs Linear Regression** - Why logistic regression is needed for classification
3. **The Sigmoid Function** - The mathematical foundation: sigma(z) = 1 / (1 + e^(-z))
4. **Log-Loss (Cross-Entropy)** - The loss function used to evaluate probabilistic predictions
5. **Model Evaluation** - Accuracy, Precision, Recall, F1-Score, and Confusion Matrix

- **Presentation Notebook** (`Group2_LogisticRegression_Presentation.ipynb`) - Used for Teams meeting presentation
