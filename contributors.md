## Project Purpose

This project implements a **Logistic Regression Classifier** to predict Pass/Fail outcomes based on study hours. It serves as a practical workshop for understanding:

- Statistical classification fundamentals
- Binary classification using Logistic Regression
- Database integration with SQLite
- Real-time data streaming
- Dynamic visualization with IPyWidgets

## Technical Overview

- **Model:** scikit-learn LogisticRegression
- **Database:** SQLite for persistent storage
- **Visualization:** matplotlib + IPyWidgets
- **Streaming:** 2-second interval data processing
- **Pipeline:** Modular functions (load_data, preprocess_data, train_model, evaluate_model)
